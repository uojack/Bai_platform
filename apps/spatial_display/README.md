# 电梯厅实时数据补充 V0.1.2

本模块是现场节目的附加数据层，不重做 EOS 产品界面。原 HTML 保存在私有备份；`build.py` 只增加一个可移除标记块，移除后与原文件逐字节一致。标题、日期、接待、新闻、天气、原声音及布局均由原节目继续负责。

D8 独立人数与摄像头 dBFS 驱动近三分钟曲线，曲线不是 PCM 音频波形。视觉语义独立检查120秒时效；未来场景声学输出标为研发参考，历史沿用不作当前值。独立语义服务尚未接入。

BaiCore/AOS 演示编排与 BaiField 网关转报均来自现有只读 runtime 接口。HOLD、未授权输出、安全静音及渲染停止照实显示；全局状态不冒充本厅扬声器实测。没有调度、静音、音量或设备写入 API。

本机私有配置 `private/spatial-display.json` 绑定已有 Pulse 数据源、已有 AOS 演示只读接口和原始页面目录。服务由本用户 `com.baiyin.spatial-display` LaunchAgent 托管。固定 GET API 支持原文件 WebView 的跨域读取；没有任意上游代理或客户端指定文件路径。

部署须先核当前 MAC、前台节目与原文件 SHA，保留原文件，阶段文件核验后原子替换；由原播放器重新载入，不重设主页或音量。原件发生其他改动则拒绝覆盖。

测试：`.venv/bin/python -m unittest tests.test_spatial_display -q`，合成来源和文件，不访问现场。真实设备截图、访问记录与回退信息保存在私有部署目录，不进入公开 Git。

EOS2.1 承接副本：`code/headquarters/elevator-live-v01`；本模块不修改8805运行实例、业务数据库或EOS应用版本。

画面仅显示位置，不显示摄像头通道编号；编号仍用于后台严格绑定。语义服务器主机由私有 `semanticHost` 指定；仅有主机地址且接口未确认时保持 `ENDPOINT_REQUIRED`，不认定算法结果已接入。视觉服务器自带的空间语义明确标为“视觉语义”。

语义交付端点从AOS语义分区的公开合同定位，私有配置区分 healthUrl 与 resultUrl。每30秒只读健康状态，45秒后撤下旧版本；校验交付角色以防开发版混入。公开healthz只证明进程与版本可读；结果接口401时仅显示“算法结果待授权”，没有读取原始音频、发推理任务、绕过鉴权或改上游服务。

## LAB02 · 原六栏接入 V0.2.0

`build_room.py` 在原房间页内绑定现有感知/认知/调度/连接/渲染/场景六栏，房名、研发模式、房间配置、时钟、总网格和原文字保持。只给旧的未接入BaiHub请求增加一个可逆的所有权保护，避免旧本地占位值每五秒覆盖新数据；附加标记和该保护移除后与原文件逐字节相同。

私有 `regions` 登记逐区域主相机与补充视角；同一批已有输入只采集一次，随后分区投影。LAB02室内为主，门口独立列出，人数不相加。新接口固定为 `/api/lab02`，页面 `/rooms/lab02.html`；电梯 `/api/elevator` 与原节目保持兼容。客户端检查region及camera双重绑定，主源缺失不自动用门口或其他区域代替。源每两秒读取，房间客户端每秒读取已有投影、原帧不推进不续新鲜度。

`web/room-data.js` 负责逐字段时效与显示标签，`room.js` 只写六个状态卡和来源/数据时刻，`room.css` 将新增值与实际声能曲线限制在原画面安全区域。不显示摄像头编号；语义鉴权、全局编排/声场及本室采样继续分开。

本次验证：15项Python、6项Node合成检查；原页可逆恢复、房间隔离、两个视野独立、过期与缺源撤值、安全静音不报运行、隐藏编号；浏览器1920×1080无越界，控制台无相关错误。实际部署另保存设备身份、文件SHA、备份、设备截图和该设备GET回执。未改EOS业务版本或数据库。

## 多房间接入 V0.2.1

每块屏使用独立区域键。私有配置中的 `regions` 可指定主视角、显示位置、补充视角及采样范围；`roomPages` 只向已注册的区域提供对应预览。摄像头未核实时，主视角设为 `null`，界面仍显示已接入的全局状态。门外数据明确标为邻近参考，同区声学研发结果标为本区参考；各视角的人数始终分别显示。

构建器只接收原有六栏模板，兼容静态六栏和已有实时写入的页面。保留原页面、接待内容和回滚副本；旧数据写入仅在本页面已接管时退出。终端继续运行原播放器。声能曲线仅在有实际样本且原页面有空间时绘制，数据停止后不伪造后续趋势。

验证：`.venv/bin/python -m unittest tests.test_spatial_display -q` 和 `node --test tests/test_room_live.cjs`。具体屏幕、点位、原文件及部署证据留在私有台账。
